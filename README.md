# Bot-ines - Frontend

Cliente web para el simulador de partidos Bot-ines. Desarrollado con React, Vite y Tailwind CSS v3.

## Prerrequisitos
* Node.js (versión 20 o superior)
* Git

## Instalación y ejecución

1. Asegurate de estar dentro de la carpeta del frontend:
```bash
cd client
```

2. Instalar dependencias:
```bash
npm install
```

3. Iniciar el servidor de desarrollo:
```bash
npm run dev
```

4. Abrir en el navegador la URL que muestra la terminal:
`http://localhost:5173`

## Scripts disponibles
* `npm run dev`: Servidor local con Hot Module Replacement (recarga instantánea).
* `npm run build`: Compilación optimizada para producción en la carpeta `dist`.
* `npm run preview`: Previsualización local del build de producción.
